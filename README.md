\# BERT Resume Matcher



A Resume–Job Description Matching System built using BERT, FastAPI, and React.



\## Features



\- Upload a resume PDF

\- Paste a job description

\- Calculate resume-job match score using BERT

\- Find matching skills

\- Find missing skills



\## Tech Stack



\- React + Vite

\- Python + FastAPI

\- BERT

\- Hugging Face Transformers

\- PyTorch

\- Scikit-learn

\- pypdf
